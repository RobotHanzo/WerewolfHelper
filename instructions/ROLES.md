# 狼人

狼人是源自於米勒山谷狼人基本篇的角色，屬於狼人陣營。

## 技能

狼人在黑夜階段擁有狼刀技能，白天混入村落中混淆好人。

* 狼刀：每夜可以睜眼與隊友見面並討論戰術與選擇殺害對象。狼人可以選擇當夜空刀或自刀。
* 自爆：狼人可以在白天任何時候翻牌自爆強制進入黑夜階段。
* 狼刀在先：在大部分板子中，狼人的行動時間早於其他有殺人技能的角色，例如女巫、獵人、幸運兒、獵魔人等，若狼人成功落刀最後一神或最後一民（即玩家沒有被其他技能保護或影響）達成屠邊或屠城的獲勝條件，即使最後一名狼人在同一晚被淘汰，狼人仍然獲勝。在面殺當中，可能影響狼刀的技能通常早於狼刀，例如守衛、魔術師等角色，這些角色的睜眼順序早於狼人。若狼人的狼刀能夠達成屠邊或屠城的獲勝條件，一般不會完成夜晚程序，直接宣佈狼人獲勝。

# 預言家

預言家是源自於米勒山谷狼人基本篇的角色，屬於好人陣營，為神職角色。

## 技能

預言家擁有一個水晶球，每夜可以查驗一位存活玩家的所屬陣營，並在白天透過發言向好人報出資訊。
一般預言家不能重複查驗玩家，但在某些局式中（例如魔術師板子）預言家查驗到的身分可能被改變，因此容許預言家重複查驗。

女巫是源自於米勒山谷狼人基本篇的角色，屬於好人陣營，為神職角色。

## 技能

女巫擁有一瓶解藥和一瓶毒藥。女巫使用解藥前，可以在晚上得知當晚被狼隊殺害的對象，並決定是否使用解藥將其救活，但女巫不可以自救；女巫也可以利用白天所得資訊，將懷疑的對象毒殺，該對象若為獵人或狼王死後不能發動技能。解藥和毒藥不可以在同一夜使用，因此一般使用毒藥的那一晚會出現至少兩死的情況。


## 房規

最常見的女巫角色房規就是容許自救（通常限於第一晚）。此房規在人數比較少的遊戲中比較常見，例如凹嗚狼人殺大部分採用九人或十人的局式，自開播以來一段很長時間採用容許女巫玩家於第一晚自救的房規，早期更不容許狼人連續兩晚落刀同一玩家
therefore, please turn this into a setting that can be modified in the dashboard

# 獵人

獵人是源自於米勒山谷狼人基本篇的角色，屬於好人陣營，為神職角色。

## 技能

獵人擁有一把獵槍，以任何方式被淘汰（殉情或被毒殺除外）可以槍殺一名玩家，也可以選擇壓槍不發動技能。
在同時有狼王的板子中，獵人發動技能時不能翻牌

# 狼王

狼王，又稱狼槍、毒狼、黑狼王，是一個狼人殺角色，屬於狼人陣營。

## 技能
- 狼王是一隻擁有額外技能的狼人角色，在自刀、被放逐或被獵槍帶走時，可以帶走一名玩家。
- 狼王可以自爆但不能發動技能，被毒殺、殉情或決鬥而死也不能發動技能。

# 魔術師

魔術師是狼人殺的遊戲角色，是好人陣營的神職角色。

## 技能
魔術師每夜可以選擇交換兩名玩家的號碼，當晚對該兩名玩家使用的技能將會被交換：

魔術師交換1號平民和2號狼人：
> 狼人落刀1號，女巫會看到1號被殺，若不使用解藥則2號被殺死；
> 女巫撒毒2號則1號被毒殺；
> 預言家查驗1號則獲得1號為狼人（2號身份）的結果，查驗2號則獲得2號為好人（1號身份）的結果；
> 獵人或狼王晚上被殺，向2號開槍則1號死亡。
被交換號碼的兩名玩家不會知道自己號碼被換。每個號碼只可以被交換一次。

若魔術師交換帶解藥的女巫牌，而女巫中刀，則仍然不能使用解藥，被交換的另一方死亡。同理，若魔術師交換帶毒藥的女巫，而女巫毒殺被交換的另一方，則女巫毒死自己；魔術師交換預言家，而預言家查驗被交換的另一方，則必定得到對方為好人的訊息。

# 機械狼

機械狼是狼人殺的遊戲角色，屬於狼人陣營。被被稱為狼隊的「大哥」。跟其他普通狼人**互不相認**，在其餘狼人死亡後會被告知繼承狼人殺人的權利。

## 技能
主動技：一場遊戲有一次機會，可以在任一夜晚開始時學習一名玩家，並依據學習對象獲得以下技能。

- 通靈師:下一晚之後每晚可以查驗一名玩家具體身分(類似石像鬼，但先刀後驗)。
- 女巫:下一晚開始可以在任意一個夜晚毒殺一名玩家（穿盾）。
- 獵人:當晚開始若達成獵人開槍條件，可以帶走一名玩家(和狼王一致)。
- 守衛:下一晚之後可以守衛一名玩家，該玩家將免疫所有夜間傷害，技能只可以發動一次。
- 狼人:繼承狼人殺人權利後，在機械狼階段先擊殺一人再進狼窩殺人。
- 平民:無特殊技能。

被動技：學習後若被通靈師查驗，查驗結果將與該名玩家相同，沒學習他人被驗則是機械狼

# 石像鬼

石像鬼是狼人殺的遊戲角色，屬於狼人陣營的特殊狼人牌。因為是特殊狼人，故被稱為狼隊的「大哥」牌。

## 技能
- 石像鬼不與狼隊相認，每晚可查驗一名玩家的具體身份。
- 遊戲開始時不帶狼刀，當其餘狼同伴出局後，石像鬼帶刀，由上帝以手勢告知。
- 石像鬼帶刀時，可先查驗玩家身份再行使狼刀。石像鬼不能自爆但可以自刀。

# 騎士

騎士為狼人殺的遊戲角色，屬於好人陣營的神職角色。

## 技能
騎士每局遊戲有1次機會可以在白天發言階段的任何玩家發言時段公佈身份牌，並選擇一名玩家與其決鬥。
- 若決鬥玩家是狼人陣營玩家，則該狼人陣營玩家被殺死，隨即進入黑夜階段；
- 反之則騎士以死謝罪，白天階段流程繼續進行。決鬥死亡的狼王、白狼王和狼美人技能不能發動。

# 獵魔人

獵魔人(又稱為授魔人)是狼人殺的遊戲角色，是好人陣營的神職角色。

## 技能
主動技:從第二個夜晚開始，獵魔人每晚都可以選擇一位玩家進行狩獵，若被狩獵的玩家是狼人該名狼人死亡，反之獵魔人死亡。

被動技:不會死於其他神職的夜間技能。

# 血月使徒

血月使徒又稱為魔狼，屬於狼人陣營。

## 技能
主動技:自爆後會直接進入黑夜，且不能指刀，當晚所有神牌的技能都會被血月使徒所封印。

被動技:若是最後一個被放逐出局的狼人，可以暫時存活並進入黑夜，夜晚血月使徒可以再擊殺一名玩家，此時若達成屠邊條件，狼人勝利。

# 白癡

白痴是源自於米勒山谷狼人新月篇的角色，屬於好人陣營，為神職角色，但由於技能強度不高，部分局式中可當作平民角色使用。

若白天放逐公投中被投出，可翻開角色牌以免疫該次放逐，但在之後的放逐公投中失去投票權利。

狼人須追刀翻牌後的白痴。

狼美人是狼人殺的遊戲角色，屬於狼人陣營。

狼美人是擁有額外技能的狼人角色，晚上可與其餘狼人玩家一同睜眼進行戰術溝通並且執行狼刀，隨後再單獨睜眼魅惑一名玩家，在狼美人出局時，上一夜被魅惑的玩家殉情且不能發動技能。狼美人不能自刀或自爆。
